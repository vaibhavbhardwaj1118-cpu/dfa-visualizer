What is DFA?

A Deterministic Finite Automaton (DFA) is a mathematical model used to recognize regular languages. For every state and input symbol, there must be exactly one defined transition.

Q

Finite set of states

Σ

Input alphabet

δ

Transition function

F

Set of final states

Mathematical Definition

A DFA is represented by a five-tuple:

M = (Q, Σ, δ, q₀, F)

DFA Conditions

  • There must be a finite number of states.
  • There must be exactly one initial state.
  • Every state must have exactly one transition for each input symbol.
  • Final states must be a subset of all states.
  • A string is accepted if processing ends in a final state.
